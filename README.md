# NIST SP 800-53 System Security Plan (SSP) & POA&M Tracker

## Overview
This repository contains a professional Governance, Risk, and Compliance (GRC) artifact set demonstrating system boundary definition, security control baselining under **NIST SP 800-53 Rev. 5**, and active remediation management via a Plan of Action and Milestones (POA&M) tracker.

## Repository Structure
* **`01_System_Security_Plan/`**: Contains the System Security Plan (`ssp_baseline.md`) outlining system categorization, boundaries, and core NIST control families (Access Control, Identification & Authentication, and System & Communications Protection).
* **`02_POAM_Tracker/`**: Contains the POA&M tracking log (`poam_template_and_log.md`) capturing identified security weaknesses, risk levels, corrective actions, and milestone schedules.

## Purpose
Designed as an industry-aligned portfolio project for GRC analyst roles, highlighting practical competency in federal security frameworks and risk tracking mechanisms.
